A aula 01 cita triggers como capacidade do Firebird, mas uma citação não é uma aula de como programar triggers. Não há programação de triggers, CREATE EXCEPTION, CHECK ou índices calculados nos exemplos examinados. Esses recursos foram retirados da base entregue.

Não foram usadas restrições UNIQUE adicionais porque não encontramos essa definição de DDL no material. A duplicidade é validada no Python.

O complemento CURRENT_TIME, usado apenas para obter o relógio junto de EXTRACT, não aparece nominalmente nos exemplos extraídos. Ele está identificado no main.py e no LEIA-ME. Não prometemos equivalência literal entre cada palavra do projeto e o material. A avaliação dos recursos permitidos cabe à professora.

para os fluxos pedidos da academia.

As regras específicas da academia são adaptações com funções, if, for,
listas, textos e SQL direto. O projeto tem mais regras que a biblioteca,
portanto não é uma cópia literal do exercício.
Além de CURRENT_TIME, o relatório usa multi_cell para quebrar linhas,
encode/decode para limitar o texto à fonte básica e opções de send_file
para definir nome de download e impedir cache antigo. São complementos
pequenos identificados, não recursos que afirmamos ter sido demonstrados
literalmente nas apresentações. Não há novas classes próprias, ORM,
framework de autenticação ou migrações no código entregue.
